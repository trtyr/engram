# D-001：后端改动授权（/jobs 路由冲突修复）

- 日期：2026-08-30 ｜ 状态：已定
- 背景：`/jobs` 前端路由与后端 API 同路径，硬刷新/书签直达返回裸 JSON。修复方案 a（Accept 分流）需要动后端路由层。
- 决策：**用户明确授权后端改动**。原文：「这个问题如果需要后端动的话，那就去动后端……你不要为了最小改动而导致这个功能残缺。」
- 影响：
  1. baseline 约束 1（后端零改动）**放宽**为：后端 API 契约稳定；为完善功能的后端改动被授权，须保持全部门禁绿（fmt/clippy/test 100）。
  2. 修复方式：GET /jobs 按 Accept 分流——浏览器导航（text/html）→ SPA index；API 客户端 → JSON。
- 关联：roadmap R1.3；open-questions#1 关闭。
