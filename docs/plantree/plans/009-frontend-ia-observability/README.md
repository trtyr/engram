# P009 · 前端信息架构与观测面重构

## 范围
前端导航与页面信息架构调整（任务并入日志、学习归位、账号分标签、网页读取归位）+ 日志观测面改造（7 天窗口/长内容收起）+ 生产 codegraph 数据根故障修复。

## 权威
- 用户逐条口述的 7 项（2026-10-03 会话）：任务/日志合并、学习归位上移、日志长内容收起、日志 7 天默认窗、已完成计数、账号拆三标签、网页读取归并 AI 能力；另加生产 codegraph 全量失效。
- 受影响模块：web（App/Logs/Todos/Account/Settings）、deploy（compose）、server/api（启动日志）、生产数据

## 关键决策
- 任务页**彻底移除**（用户拍板选项：日志页内独立区块展示 job 记录，不再有单独入口）——jobs 数据源保留，仅前端归并。
- 数据根口径：`AGENT_MEMORY_DATA_DIR` 必须显式注入且等于卷挂载点；容器形态下 HOME fallback 会写进可写层（见部署档案）。
