# 设置页配置面（settings-page）

Settings 新增「节律」分区（与 Providers/路由/API 密钥/危险区域平级）。

## 配置项

| 配置 | 类型 | 默认 | 说明 |
|---|---|---|---|
| cron 总开关 | bool | off | 一键停所有定时任务（出事时的红色按钮） |
| full 蒸馏周期 | 每日时刻 / 关 | 03:30 | 维护性 cron 层 A 的主档 |
| 快照收敛兜底 | 每日 / 关 | 随 full | organize converge 的定时兜底 |
| 分面退休检查 | 每周 / 关 | 随 full | R3 年龄检查 |
| 静默时段 | 时间窗 / 关 | 关 | 窗口内 due 任务顺延到窗外（不打扰） |
| AI 主动记录 | 只读展示 | — | 展示在役 amk_ key 及其最近写入时间（"谁在记"） |

## 可观测性（同页）

- **最近节律事件**：近 20 条 cron 触发记录（任务/时刻/结果/耗时），复用 jobs 表
- **冲突事件**：上述 conflict-matrix 各防线触发时的留痕（如「append 被拒：会话已蒸馏」），设置页可见
- 数据源全部复用 jobs 表 + 审计行，不新建表

## 边界

- 配置存储：settings 域已有配置面（llm_providers 等），节律配置走同域新表或 kv（实施时定）
- 服务端 cron 宿主未定（open-questions #2），配置面字段随宿主选型微调
- 危险性低：本页不含破坏性操作（清空仍在危险区域）
