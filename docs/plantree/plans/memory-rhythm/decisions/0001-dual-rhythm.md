# D-001 双节律方向（2026-09-01）

**决策**：记忆记录采用双节律——AI 主动请求 + cron 定时，两条腿长期共存；冲突防御先行（矩阵化）；Settings 增设节律配置页。

**背景**：用户北极星「真记性不需要主人提醒自己在记」。AI 主动已上线（session-write/append + 防抖触发蒸馏），但依赖 AI 自觉；cron 是不依赖任何自觉性的兜底。此前"自动节律"（pi extension 钩子）拍板缓做，本次用户重新提起并扩展为双节律 + 冲突 + 配置页的完整方向。

**用户原话**：「以后会有两个方式，一个是 AI 主动请求记录，一个是 cron 定时是吧？可以，不过你要考虑到相关的极端情况，比如说 AI 和 cron 在某一个时刻冲突等等情况。你在设置那里，需要加一个相关的配置页面。」

**后果**：

- 层 A（维护性 cron：full 蒸馏/快照收敛/退休检查定时化）无语义歧义，待宿主选型后即可动
- 层 B（记录性 cron）边界未定，见 open-questions #1
- 冲突防御大部分已内建（8 项既有防线复用），增量 5 项进 R-2
- 配置页进 Settings 新分区，数据面复用 jobs 表
